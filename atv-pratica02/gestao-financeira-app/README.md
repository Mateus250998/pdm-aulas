# Gestão Financeira App

Frontend mobile da aplicação de gestão financeira desenvolvida para a atividade prática de PDM.

## Tecnologias previstas

- React Native
- Expo
- Axios
- React Native SVG

## Funcionalidades

- Tela de login com validação de acesso
- Mensagem de boas-vindas com nome do usuário autenticado
- Listagem de receitas e despesas
- Filtro por mês e ano
- Resumo financeiro
- Gráfico de pizza por categoria
- Cadastro de transações
- Edição e exclusão de transações por toque longo
- Categorias vindas da API
- Cadastro de categorias customizadas
- Integração com backend via API Client HTTP
